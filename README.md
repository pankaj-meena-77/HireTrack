# HireTrack

### Smart Career & Opportunity Platform

**One platform. Multiple opportunities. Better career choices.**

HireTrack is a free career and opportunity platform designed to connect students, job seekers, recruiters, and companies.

## Project Vision

Help users discover relevant career opportunities, understand their compatibility, and manage their applications in one place.

## Core Features

- Student and recruiter accounts
- Smart opportunity matching
- Internship and job discovery
- Application tracking
- Saved and comparison opportunities
- Company verification
- Email and in-app notifications
- Separate student, recruiter, and admin dashboards

## Technology Stack

**Frontend**
- React.js
- Vite
- Tailwind CSS

**Backend**
- Node.js
- Express.js
- MongoDB

**Tools**
- Git and GitHub
- VS Code
- Postman
